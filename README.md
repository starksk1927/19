# Happy Birthday Kaviii 🩵 | Dedicated to My Wifee

An ultra-luxurious, romantic birthday web experience crafted with infinite love by **Hari** for his dearest wifee, **Kaviii**.

## 🌟 Highlights & Features
- **Private Vault Entry**: Protected with 4-digit PIN (`1019` - her birthday) with SHA-256 verification and zero client DOM leakage.
- **Childhood Memories 💋**: Nostalgic showcase of Kaviii's earliest milestones and memories.
- **Our Love Story Timeline**: Interactive journey of how love blossomed.
- **Interactive Polaroid Gallery**: 3D flip cards with memories and sweet notes.
- **Hari's Singing Gift 🎙️**: Hari singing *"Magale"* with an interactive vinyl record player, dedicated to his wifee, one & only daughter, and papa kutty.
- **Interactive Birthday Cake**: Realistic flickering candle flame that can be blown out with celebratory confetti and personalized greeting (`KAVIII`).
- **Couple Soulmate Quiz & Certificate**: Fun romantic quiz awarding a signed soulmate certificate.
- **Virtual Love Lock & Wax-Sealed Letter**: Eternal engraved love lock and handwritten letter.
- **Mobile Optimized**: Custom tailored for smooth 120Hz scrolling, touch comfort, and seamless viewing on Motorola Moto g45 5G and all mobile devices.

## 🚀 Tech Stack
- React 18 + Vite
- Tailwind CSS with custom glassmorphism and keyframe animations
- Lucide React icons
- Canvas Confetti & Web Audio API sound effects

## 🛠️ Local Development
```bash
npm install
npm run dev
```

## 🌐 Deploy on Vercel
Push to GitHub and import repository on [Vercel](https://vercel.com).
Framework preset: **Vite**
Build command: `npm run build`
Output directory: `dist`
